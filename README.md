# Brad.log｜Brad 的工程筆記

記錄技術學習、實作過程與問題排查，讓零碎的發現逐步累積成可以回顧與分享的工程筆記。

## 內容方向

- **短筆記**：新理解的概念、工具與使用技巧。
- **主題筆記**：持續整理與修訂的技術知識。
- **實作與排錯**：問題背景、嘗試方法、驗證結果與解法。
- **閱讀紀錄**：參考資料、重點整理與待驗證的問題。

## 網站規劃

- 模板：[AstroPaper](https://github.com/satnaing/astro-paper)
- 文章格式：Markdown
- 託管：GitHub Pages
- 更新流程：完成部署設定後，推送筆記至 GitHub 即自動更新網站。
